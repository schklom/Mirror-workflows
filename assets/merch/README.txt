openGym merch artwork
=====================
Brand: lime #a3e635 (light variants use #84cc16 for contrast on white),
dark #0c0e12, ink #eef1f6. Mark geometry 1:1 from frontend/resources/icon.svg.

DESIGNS
  mug-log-card       fake workout log: "Coffee - 3 x 12 - inf kg", NEW PR pill
  mug-rest-timer     90s ring, "the only set you don't have to finish"
  mug-no-cloud       "NO CLOUD. NO ADS. JUST REPS." over the progress bars
  mug-wrap           full 360 wrap: "sudo lift / permission granted" on the back,
                     logo + opengym.duarte-santos.ch on the front, tiled dumbbells
  mug-wrap-plain     the same wrap without the tiled dumbbells
  bottle-hydration   ml scale with training labels (warm-up -> PR attempt)
  bottle-minimal     stacked mark + wordmark, minimal
  bottle-band        tiled dumbbells with a solid lime band around the middle
  bottle-band-plain  the same band without the tiled dumbbells

PATTERN ONLY (drop in as your own background layer)
  pattern-mug-wrap   2475 x 1155 - matches the mug wrap
  pattern-bottle      900 x 2400 - matches the bottle designs
  pattern-square     2400 x 2400 - generic, for anything else
  Every dumbbell in these files is complete - none is cut off at the edge.

VARIANTS (each design)
  -dark         full-bleed dark background   -> black/dark mug, printed edge to edge
  -light        white background             -> white mug, standard sublimation
  -transparent  artwork only, no background  -> black mug/bottle where only the
                artwork is printed, and for laser engraving.
                No semi-transparent ink anywhere: every element is fully opaque.
                Half-transparent lime disappears once it is composited on black
                (13 % lime over black IS black), which is why the tiled dumbbells
                did not show up in the mockup. They are a solid #587a24 now.

PIXEL SIZES (all 300 dpi)
  mug panels    2400 x 2400 px  = 203 x 203 mm  (crop/scale to your printer's panel,
                                                 usually ~85 x 85 mm one side)
  mug wraps     2475 x 1155 px  = 210 x  98 mm  (standard 11 oz full-wrap template)
  bottles        900 x 2400 px  =  76 x 203 mm  (vertical wrap/print area)
  pattern-square 2400 x 2400 px = 203 x 203 mm

Need another size, ratio or wording? The .svg next to each .png is the source -
it is vector, so any size re-renders without quality loss.

_sheet.png / _sheet-light.png / _sheet-onblack.png are previews, not for print.
_sheet-onblack.png shows the -transparent files composited on pure black.
