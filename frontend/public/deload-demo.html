Epley-based automatic deload

Synthetic review fixture. Select a predefined case, then trigger the deload. The target 1RM uses the prescribed weight and reps; a partial failure does not substitute the lower actual reps. Output load is always bounded by the attempted current load.

What to check
  • Linear keeps the prescribed reps and moves to the nearest valid load grid.
  • Double progression can keep the current load with fewer reps when that is the closest valid Epley solution.
  • Per-side estimates use reps per side and return an even total.
  • The below-step case holds 1 kg rather than incorrectly increasing it to 2.5 kg.
Formula: 1RM = weight × (1 + reps / 30); deload target = estimated 1RM × 0.9.
