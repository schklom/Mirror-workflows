openGym t-shirt artwork
=======================
All files are transparent PNG with NO background - the shirt colour IS the
background. Nothing is semi-transparent: every element is fully opaque, so it
survives being printed on black (half-transparent lime disappears on dark fabric).

DESIGNS
  tee-front-sudo-lift  "$ sudo lift" as a terminal line, "permission granted",
                       logo underneath                        3600 x 2402  (12.0 x 8.0 in)
  tee-front-no-cloud   "NO CLOUD. NO ADS. JUST REPS." over the
                       progress bars                          3600 x 3334  (12.0 x 11.1 in)
  tee-front-logo       big dumbbell + wordmark + tagline       3600 x 2668  (12.0 x 8.9 in)
  tee-back-tour        back print: the week as a tour poster,
                       MON bench press ... SUN coffee 3 x 12   3600 x 3894  (12.0 x 13.0 in)
  tee-chest-lockup     left chest: mark + wordmark             1050 x 224   (3.5 x 0.7 in)
  tee-chest-mark       left chest: dumbbell only               1050 x 549   (3.5 x 1.8 in)

VARIANTS
  -ondark   light ink (#eef1f6) + lime #a3e635  -> black, charcoal, navy shirts
  -onlight  dark ink (#12151b) + lime #84cc16   -> white, natural, heather shirts
            (the lighter lime would be too weak on white, so it is a shade deeper)

All sizes are 300 dpi and cropped tight to the artwork, so the printer scales the
design itself instead of a lot of empty canvas. 12 in wide is the usual DTG front
width; upload as-is and place it, do not stretch.

_sheet-ondark.png / _sheet-onlight.png are previews on a mock shirt colour, not for print.
